# Doravin Prayanam 🎁

Colorful interactive cartoon adventure game.

## Run locally
Open `index.html` in a browser.

## Files
- `index.html` — game screens
- `script.js` — game logic, voice and music
- `style.css` — colorful UI and animations
- `images/` — game images
- `sound/` — background music

## GitHub Pages
Keep `index.html`, `script.js`, `style.css`, `images/`, and `sound/` at the repository root.
